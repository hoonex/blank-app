## 적용 원칙

이번 디자인 작업은 [edisonmbli/refactoring-ui-skill](https://github.com/edisonmbli/refactoring-ui-skill)을 **진단 규칙집**으로 활용했다. 이 저장소는 *Refactoring UI* 도서의 저자 공식 플러그인이 아닌 독립 MIT 프로젝트이며, 도서 내용 전체를 복제하거나 공식 승인을 주장하지 않는다. Claude Code의 `/plugin install` 명령은 현재 서비스 런타임에 필요하지 않다. 디자인 규칙은 이 문서와 실제 Flow CSS에 반영하며, Skill 전체를 런타임에 배포하지 않는다.

**기존 결정 우선:** Leptos/Rust/Wasm 유지, Tailwind 도입 금지, 무작위 신규 CSS 색상 팔레트 금지. 기존 `--paper`, `--paper-low`, `--ink`, `--muted`, `--accent`, `--surface`, `--night` 등을 사용한다. 오렌지/웜 뉴트럴과 5개 하단 메뉴, 손그림 아이콘, 달력 휠, 현재 교시, NEIS 정보, 전체 주간/월간 급식 동작을 유지한다. 기능 추가보다 사용자가 첫 화면에서 정보를 빨리 읽는 것이 우선이다.

## 디자인 토큰 계약

- 공간 스케일: `4 / 8 / 12 / 16 / 24 / 32` CSS px. Flow의 기존 토큰으로부터 파생해 보조 공간 값을 정함.
- 글자: 기존 Inter / Pretendard / Noto Sans KR, 400 이상. 제목과 본문은 이미 존재하는 서체 계열을 유지.
- 색상: `--ink` 1차, `--muted` 2차, `--faint` 가장 낮은 우선순위. 브랜드색 `--accent`는 상태·행동에만 쓰기.
- 깊이: 대부분 무광 단면. 레이어는 실제 열리는 다이얼로그와 플로팅 내비게이션에만 강한 그림자.
- 반응형: 320, 390×844, 844×390, 768×1024, 1024×768, 1366×768, 1920×1080. 가로 스크롤/클리핑, 첫 화면 정보 밀도, 글줄 겹침을 확인.
- 상태: 정보가 없으면 ‘없음/표시되지 않음’으로 표시, 추정 수업·메뉴·공식 일정 생성 금지.

## 향후 가치 있는 기능 후보 — 현재 미구현

1. **시험·행사 집중 보기:** 실제 학교 공식 학사일정에서 시험/방학/재량휴업일만 필터. 학교마다 다른 명칭을 확인하고 추정 분류 금지.
2. **급식 검색·조건 표시:** NEIS 알레르기 원문 표기가 있을 때만 검색/표시. 메뉴명으로 알레르기 유발 식품을 AI 추정하지 않기.
3. **오늘 한 장을 이미지로 공유:** 사용자 클릭 시 캔버스로 원본 날짜·과목·급식만 렌더링, 개인정보 노출 안내 및 저사양 기기 성능 측정 선행.
4. **학교별 등교/하교 바로가기:** 학교에서 공식 시간표를 공개했을 때만 특정 학급의 시작·종료 시각 제공.
5. **학사일정의 주변 날짜 키보드 탐색:** 휠 드래그와 함께 방향키·스크린리더 제어 강화.
6. **버스 정류장 개인 고정:** 개인정보를 서버에 보내지 않는 로컬 즐겨찾기, 실제 BIS 도착정보와 구분.

이 후보들은 흥미 위주의 장식이 아니라 정보 탐색 시간 단축을 증명할 수 있을 때만 개발한다.
