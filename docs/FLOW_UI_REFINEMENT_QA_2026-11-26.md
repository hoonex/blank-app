**사용자 동작 테스트**: 320/390/844px에서 Today 날짜 11월 26일→27일로 클릭, 공유창 제목 11.27 금요일로 갱신, Escape 닫기·초기 버튼으로 포커스 복귀, 주간 탭에서 공유 비표시·하루 탭에서 복귀, 열기/닫기 중 오류 없음.

**클립보드**: 실제 11월 26일 화면의 수업 4개(문학/영어Ⅱ/스포츠 생활2/진로활동)와 급식 6개를 복사함. 식단 원본의 숫자 알레르기 코드(예: `(5.6.13)`)는 공유 요약에서 제외하되 실제 메뉴명을 지우지 않음. 11월 27일은 당일 실제 수업 2개를 기준으로 내용 갱신 확인.

**디자인 QA**: 390/1366px Today·학교·일정, 320px Today, 844×390 Today 화면 스크린샷 촬영 및 육안 확인. 초기 320px에서 공유 버튼이 아래 행으로 내려가는 문제 → 절대 위치로 조정했으나 실제 날짜 변경 시 Native 하루 버튼과 충돌(실패) → 104px 컨트롤 그룹을 사용한 2행 grid로 수정. 이후 최종 320px ‘과목 수정’ 버튼 폭 61.8px, ‘공유’ 38.3px, 서로 겹치지 않고 클릭 확인. 다크 테마 요약 dialog와 학교 링크 시각 점검, 읽기 가능한 색상·대비 토큰 사용. 844px 가로 짧은 높이에서는 기존 플로팅 탭이 일부 본문 위에 나타나는 현상은 기존 앱 동작이며 이 작업 범위에서 변경하지 않음.

**접근성**: 네이티브 HTML `dialog`(Escape/포커스 복귀/모달 배경), 버튼/링크 키보드 포커스, 상태 메시지 `role=status`, 320px 작은 화면, `prefers-reduced-motion` 대응.

## 미변경 / 제한

- Rust/Wasm·NEIS·버스 위치/도착·달력 휠·날짜 scrubber·기존 5탭·광고 흐름·원본 시간표 수정 기능은 수정하지 않았다.
- 네이티브 기기 공유는 `navigator.share`을 지원하는 브라우저에서만 표시하며 Android 실기기로 직접 테스트하지 않았다.
- 현재 표시된 화면 정보만 공유하므로 데이터에 누락이 있으면 결과에서도 그 부분은 누락됨. 공식 학교 공지가 우선임을 모달에 명시.
- 사용자가 날짜를 바꿨을 때 보여 주는 급식은 기존 UI에서 선택한 급식 날짜의 메뉴를 읽는다. 일일 캘린더 날짜와 급식 날짜가 독립적으로 변경될 수 있다는 사실을 각 데이터 제목으로 보존한다.
