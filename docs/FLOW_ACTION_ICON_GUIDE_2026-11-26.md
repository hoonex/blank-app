# Flow School: 문자형 가짜 버튼 제거와 공통 액션 아이콘 (2026-11-26)

## 목표
문자 `⌄`, `‹`, `›`, `↗`를 버튼이나 아이콘처럼 꾸미는 패턴을 없앤다. 눈속임처럼 보이는 장식이나 불필요한 카드 중첩을 추가하지 않는다. 기존 정동고 전용 캠퍼스 지도 프로젝트는 **절대로 변경하지 않는다**.

## 실제 화면에서 찾아 고친 부분

| 화면 | 기존 | 이번 변경 |
|---|---|---|
| 오늘 날짜 헤더 | 월 옆의 문자형 `⌄` | **달력 SVG**와 전체 월 이름을 터치하는 44px 버튼 |
| 오늘 날짜 이동/월 선택 | `‹`와 `›` 글자, 30~36px 버튼 | 동일한 벡터 방향 아이콘, 44×44px |
| 급식 주간·월간 탐색 | `‹`와 `›` 글자, 29px 버튼 | 동일한 벡터 방향 아이콘, 44×44px |
| 일정 전체 목록 | 목록 우측에 문자 `›` | SVG, 목록 전체가 기존 날짜 선택 버튼 |
| 학교 바로가기 | 문자 `↗` 및 106px 빈 카드 | 외부 열기 SVG, 86px의 정돈된 타일 |
| 버스 주변 정류장 | 정류장 우측 문자 `›` | SVG, 기존 정류장 선택 동작 보존 |
| 설정 | 다시 선택 및 대학 모드 끝에 문자 `↗` | 내부 동작은 오른쪽 방향 SVG, 외부 열기는 외부 열기 SVG |
| 설정 버튼 | 일부 37~39px 높이 | 최소 44px 동작 영역 |

## 구현 원칙

- 모든 액션 SVG는 기존 `flow-icons-handdrawn-v1.js`의 24×24 그리드와 라운드 스트로크 규칙을 재사용한다. 외부 폰트·네트워크·서드파티 아이콘 라이브러리 없이 렌더링한다.
- 액션 아이콘은 `aria-hidden`이고, 버튼에는 사용자의 목적을 설명하는 접근성 이름을 제공한다. 월 선택 다이얼로그는 `aria-controls`와 `aria-expanded` 상태를 동기화한다.
- 기능 스크립트는 DOM을 만들 때 처음부터 SVG를 생성한다. 단, Rust가 이미 출력하는 설정 화면의 기존 텍스트는 같은 아이콘 공급자의 MutationObserver가 실제 렌더링 시 치환한다. 기존 이벤트 연결과 Rust/Wasm 바이너리는 변경하지 않는다.
- 아이콘 스크립트는 기능별 `defer` 스크립트보다 앞에서 실행되도록 이동했다. 의존 코드가 먼저 실행되는 문제를 피한다.
- CSS 오버레이를 새로 늘리지 않고 **활성 파일의 실제 선언**을 수정했다. 변경 파일의 캐시 버스팅 쿼리를 통일했다. 메인 CSS의 SRI는 변경하지 않았다.
- 월간 회전 카드는 별도 공간 제스처가 있는 복합 UI이므로 이번 벡터 정리 과정에서 회전 엔진을 변경하지 않는다.

## 검증

- `node scripts/qa-flow-action-icons.mjs`: 활성 UI 5종의 SVG 공급 의존, 글리프 없는 소스, 접근성 속성, 44px 목표, 정적 에셋 쿼리 검사.
- `node scripts/qa-flow-design-system.mjs`: 기존 카드 역할·경계·효과·SRI 등 9개 회귀 계약 유지.
- Chrome Playwright: 320/390/768/1366px 밝은 테마 및 390px 어두운 테마에서 5/5 통과. 날짜 선택 → 월 선택 다이얼로그 → 급식 주간/월간 → 일정 → 학교 → 버스 → 설정 → 오늘 복귀를 실제 클릭. SVG 표시·누락 문자·CSS 로드·가로 넘침·JS 예외 확인.
- 버스 GPS 주변 정류장의 실제 기기 위치와 손가락 제스처, 보조기기 스크린리더 발화, 다양한 학교 계정의 데이터 정확성은 이 QA로 검증하지 않았으므로 별도로 해야 한다.

## 후속 원칙
앞으로 새 인터랙션을 만들 때 이 파일의 아이콘과 공통 터치 크기를 재사용할 것. 새 `v`·`>`·`↗` 문자 버튼이나 역할 없는 그림자·호버 리프트를 도입하지 말 것. 내용이 없는 카드의 높이를 임의로 키우지 말고 실제 정보 밀도에 맞춘다.
