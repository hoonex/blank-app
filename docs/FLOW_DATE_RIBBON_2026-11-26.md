# Flow School · Date Ribbon V2 — 2026-11-26

## 사용자 결정 및 범위

사용자 피드백: 기존 흰색 컴팩트 날짜 카드도 만족스럽지 않으며, 이전의 날짜 속도 손잡이·원래 방식에 얽매일 필요가 없음. 공유 기능은 불필요. 따라서 기존 날짜 UI에 디자인만 덧칠하는 대신 **별도 주간 날짜 리본 + 필요할 때만 열리는 월간 선택창**으로 교체.

- 공유 UI/공유 데이터 접근은 **현재 운영 기준 이미 제거되어 있었음**. 이번 변경에서 다시 추가하지 않는다.
- 기존 Today 날짜/수업/급식 데이터는 그대로; 새 UI의 클릭은 Leptos가 실제 만든 날짜 버튼의 기존 핸들러를 호출한다. 시간표·급식·날짜 원본의 추측과 복제 금지.
- Flow School만 수정. 정동고 3D 캠퍼스 지도는 별개, 수정하지 않음.
- 5개 탭, 시간표 수정, 급식 주간/월간, 달력 휠, 버스, 학교 선택, 광고 코드 보존.

## 실제 참고

- [Fantastical의 DayTicker](https://flexibits.com/fantastical-ios/help/calendar-views): 날짜 탐색을 아래 일정과 연결하고, 주기적인 탐색은 짧은 리본에서 처리하는 개념
- [Apple HIG · Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers): 더 먼 날짜는 추가 선택 UI를 필요할 때만 노출하는 구조
- [Refactoring UI Skill](https://github.com/edisonmbli/refactoring-ui-skill): 정보 우선순위, 과도한 카드/레이블 제거, 그룹 간 간격
- [Material Components DatePicker](https://github.com/material-components/material-components-android/blob/master/docs/components/DatePicker.md): 월 탐색 및 날짜 상태의 키보드·터치 선택

참고한 것은 정보 구조·탐색 패턴이며 원본 코드, 이미지, 브랜드는 복사하지 않는다.

## 안정성·성능

- 오늘 날짜는 실제 Leptos 버튼의 날짜 레이블에서 월/일을 읽고 가장 가까운 연도를 추정하여 장치 시간대와의 불일치를 완화한다.
- 화면 리본은 7개 또는 데스크톱 14개 버튼만 만든다. 전체 181개 원본 버튼을 또 만들지 않는다.
- 원본 레일의 날짜 선택 클래스/ARIA 변화만 작은 MutationObserver 한 개로 확인. 전역 무한 관찰·네트워크 요청·백그라운드 렌더링 없음.
- 다른 달을 선택하면 원본 날짜 버튼을 클릭하여 Leptos 상태가 갱신되도록 연결. 월 선택창은 기존 원본 범위의 날짜만 활성화.
- 기존 학교 선택 완료 후 처음 Today 화면이 나타나는 지연 상황도 클릭 후 소량의 재시도로 대응. 다만 실제 신규 사용자 학교 검색 완료까지의 E2E는 별도 기기에서 추가 확인 필요.
- `prefers-reduced-motion`을 따르면 주간·다이얼로그 시각 이동을 생략한다.

## 자동화 검증

Chrome Playwright + 실제 운영 Rust/WasM·NEIS와 동일한 코드 경로, 후보 에셋만 request intercept로 대체하여 검사.

- **320, 360, 390, 428, 768, 1366, 1920px:** 리본 장착, 날짜 탭 후 Leptos 원본 날짜 변경, 오늘 복귀, 주 이전·다음, 월 선택창 열기/날짜 선택/닫기, 5탭 전환 뒤 중복 없음, 공유 버튼 없음, 가로 넘침 없음, JS 예외 없음: **7/7 화면 통과**.
- **320, 390, 1366px:** 월 선택창에서 2026-12-01을 선택하면 원본 표시가 12.01로 바뀜. 오늘 복귀 시 11.26. 월 달력 화면 범위 내 표시.
- **320, 390, 870px:** CDP 실제 터치 이벤트(touchStart/move/end)로 주간 스와이프 성공. 주가 다른 화면을 볼 때 '오늘' 버튼 표시.
- **871px:** 모바일↔데스크톱 경계에서 14일 리본, 월 선택창/ESC 닫기/키보드 좌우 이동 정상.
- **다크 모드:** 최종 전환 뒤 배경 rgb(25,27,24), 글자 rgb(240,241,233); 가로 넘침 없음.
- 실제 Samsung Android 기기에서의 터치/스크린리더 테스트는 **미실시**.
